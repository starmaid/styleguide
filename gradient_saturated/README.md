# Gradient Saturated

This is the style that uses brightly colored soft gradients to make calming, smooth, and modern looking graphics.

## Examples

- [Manifold Garden](https://manifold.garden/)
- [I Love Hue](https://i-love-hue.com/)
- A cover for the book Scattered All Over The Earth

## Tenants

    COLOUR - Move each tile to its perfect place within the spectrum
    HARMONY - Create order out of chromatic chaos
    PERCEPTION - Learn to see the smallest differences between shades
    SERENITY - Lose yourself in a tranquil world of colour and light

## Fonts

geometric, sans serif, black and white. monospace for titles.

## Audio

Sounds like wind chimes. Ambient and evolving pads. Algorithmic, but slow.
